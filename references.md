# 📚 State-of-the-Art Literature (Underwater Image Restoration)

This repository is built upon the foundational research of several recent papers in the field of underwater computer vision.

### 1. A Comprehensive Survey on Underwater Image Enhancement Based on Deep Learning (Cong et al., 2024)
- **Summary:** An excellent baseline overview of how deep learning methods surpass traditional physical scattering models. It details the transition from CNN-based models to modern architectures for handling color attenuation, backscattering, and turbidity.

### 2. UniUIR: Considering Underwater Image Restoration as An All-in-One Learner (Zhang et al., 2025)
- **Summary:** A cutting-edge approach that treats various underwater degradations (color casts, blur, low light) through a unified all-in-one learning framework, rather than relying on task-specific models. Highly relevant for building robust, scalable pipelines.

### 3. Contrastive Semi-Supervised Learning for Underwater Image Restoration via Reliable Bank (Huang et al., 2023)
- **Summary:** Addresses the critical lack of paired "clean vs. degraded" underwater datasets. It introduces a semi-supervised contrastive learning method, which is a powerful strategy when ground-truth (reference) images are scarce.

### 4. Task-Friendly Underwater Image Enhancement for Machine Vision Applications (IEEE, 2024)
- **Summary:** Focuses on the "why" of image enhancement: ensuring that restored images actually improve downstream machine vision tasks (like object detection or autonomous navigation), rather than just looking subjectively better to the human eye. This perfectly aligns with our project's goal.
